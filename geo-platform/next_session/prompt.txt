== KEY RULES (read 03_architecture.md for full details) ==

- Fire-and-forget: all refresh_* functions use try/except, never re-raise
- Redis: always import from app.cache — never import redis directly
- SQL injection: compile_expression() puts field names as VALUES to properties->>:f_N, never interpolated
- Shard DB: raw text() SQL only — no ORM — always include layer_id in WHERE
- record_version() must be called in the SAME transaction as the UPDATE it records
- POST /layers/identify must be registered BEFORE /{layer_id} routes (FastAPI route order)
- asyncio.to_thread() for pyshp and fiona (both are sync libs)
- No React Query — plain axios + useState/useEffect
- terra-draw (not @mapbox/mapbox-gl-draw) for map drawing
- Windows: use venv\Scripts\python, WindowsSelectorEventLoopPolicy already set
